# 🐍 Introducción al uso de Python

Repositorio de prácticas y ejercicios realizados durante mi formación en **2º de Desarrollo de Aplicaciones Web (DAW)**.

En este repositorio se recopilan diferentes ejercicios destinados a aprender y practicar los fundamentos del lenguaje **Python**, comenzando por conceptos básicos y avanzando progresivamente hacia estructuras y problemas más complejos.

Actualmente, el repositorio incluye ejercicios relacionados con:

- 🔹 Fundamentos de Python
- 🔹 Variables y tipos de datos
- 🔹 Operadores
- 🔹 Estructuras básicas
- 🔹 Resolución de problemas mediante código
- 🔹 Prácticas de programación

## 🧠 Objetivo

El objetivo principal de este repositorio es **aprender los fundamentos de Python mediante la práctica**, desarrollando progresivamente la capacidad para analizar problemas, plantear soluciones y convertirlas en código.

Además de conseguir que los programas funcionen, se busca mejorar progresivamente aspectos como:

- ✨ Organización del código.
- 🧩 Resolución de problemas.
- 📝 Claridad y legibilidad.
- 🔎 Análisis de errores.
- 🔄 Mejora progresiva de las soluciones.
